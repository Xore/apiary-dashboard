# Runbooks

Operational procedures are split by action:

- [Deployment](runbooks/deployment.md)
- [Environment](runbooks/environment.md)
- [Cutover](runbooks/cutover.md)
- [Rollback](runbooks/rollback.md)

The [release gates](release-gates.md) decide whether an operator may start the cutover runbook. Legacy removal is a later, separately authorized contraction.
